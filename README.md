
# 📈 Market Live Tester

**A lightweight Python dashboard for monitoring multiple markets in one
place.**

💵 Currency   ·   🥇 Gold   ·   🛢️ Oil   ·   ₿ Crypto   ·   🇮🇷 TSE

------------------------------------------------------------------------

## ⚡ What does it do?

Fetches market data from public sources, converts related values to
**IRR**, and displays everything in a simple graphical dashboard with
automatic refresh.

``` text
🌐 Public APIs
     │
     ▼
📥 Fetch prices
     │
     ▼
🧮 Calculate / Convert
     │
     ▼
🖥️ Tkinter Dashboard
     │
     ▼
📋 Live Logs
```

## 🔄 Simple & automatic

**⏱️ Refresh:** every 10 seconds\
**🔄 Manual:** instant refresh button\
**📋 Logs:** fully copyable for debugging\
**🔑 API Keys:** not required for the current prototype

## 🎯 Why?

Instead of checking several markets separately:

> **One small dashboard → multiple markets → one glance.**
